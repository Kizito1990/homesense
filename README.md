# HomeSense

**Professional Smart Home Monitoring & Control Platform**

HomeSense is a real-time web application that allows users to monitor environmental conditions and control devices in a smart home. It features live data updates, automation rules, and dynamic management of rooms, sensors, and actuators.

## Features

- Real-time monitoring of temperature, humidity, air quality, and more
- Control of lights, blinds, irrigation, and other actuators
- Automation rules engine
- Dynamic addition of rooms, sensors, and actuators
- Clean and responsive user interface
- Integration with external weather and air quality APIs

## Architecture

The Single Page Application never communicates directly with the IoT device. All data exchange happens through Firebase Realtime Database.

## Tech Stack

- **Frontend**: HTML5, Bootstrap 5, jQuery
- **Backend / Database**: Firebase Realtime Database
- **IoT**: Python (Raspberry Pi)
- **External APIs**: Open-Meteo
